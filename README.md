# 📊 حاسبة المعدلات

واجهة ويب تفاعلية لحساب المعدلات الجامعية والمدرسية بسهولة وسرعة.

## ✨ المميزات

- ✅ إضافة مواد متعددة برسم بياني لسهولة الاستخدام
- 📊 حساب المعدل الحسابي (المتوسط البسيط)
- ⚖️ حساب المعدل المرجح (Weighted Average)
- 🎓 عرض التقدير (ممتاز، جيد جداً، جيد، مقبول، ضعيف)
- 💾 تحميل النتائج في ملف CSV
- 🎨 واجهة حديثة وسهلة الاستخدام
- 📱 واجهة متوافقة مع جميع الأجهزة

## 🚀 كيفية الاستخدام

1. افتح ملف `index.html` في متصفحك
2. أدخل اسم المادة والدرجة وعدد الساعات (الوحدات)
3. اضغط على "إضافة مادة"
4. كرر الخطوات لإضافة جميع المواد
5. ستظهر النتائج تلقائياً:
   - **المعدل الحسابي**: متوسط درجاتك
   - **المعدل المرجح**: المعدل مع حساب عدد الساعات
   - **التقدير**: تقييمك العام

## 📋 جدول التقديرات

| التقدير | النسبة |
|--------|-------|
| ممتاز | 90-100 |
| جيد جداً | 80-89 |
| جيد | 70-79 |
| مقبول | 60-69 |
| ضعيف | أقل من 60 |

## 🛠️ الملفات

- `index.html` - الميزات الرئيسية والعناصر
- `style.css` - التصميم والألوان والمظهر
- `script.js` - المنطق والحسابات والوظائف

## 💻 المتطلبات

- متصفح ويب حديث (Chrome, Firefox, Edge, Safari)
- لا تحتاج إلى تثبيت أي برامج إضافية

## 🎯 الوظائف الرئيسية

### إضافة مادة
أدخل معلومات المادة واضغط "إضافة مادة"

### حذف مادة
اضغط على زر "حذف" بجانب المادة التي تريد حذفها

### مسح الكل
احذف جميع المواد المضافة

### تحميل النتائج
حمّل نتائجك في ملف Excel يمكن فتحه وتعديله

## 📝 ملاحظات

- يمكنك الضغط على Enter بعد إدخال عدد الساعات لإضافة المادة مباشرة
- الدرجات يجب أن تكون بين 0 و 100
- عدد الساعات يجب أن يكون رقم موجب
- جميع الحسابات تتم مباشرة في المتصفح (آمن وسريع)
